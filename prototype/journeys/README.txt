FreeDME Journey Explorer
Open FreeDME Journey Explorer.html in a browser. Self-contained; no installation, network or backend required. The full-demo link uses the internet.

11 independent scripted scenarios, 50 stages. Choose a pathway, use the next action/previous buttons, or jump to a numbered stage. Donor and recipient panels update together. SMS history accumulates through the selected stage; all messages are illustrative simulations.

Baseline: PRS v0.10 plus subsequent user decisions including handoff negotiation and removal of recipient-view donor mobile. Requirement references appear per scenario. Unresolved notification/recovery policies are explicitly retained as open.

Browser verification: all 11 scenario endpoints render and disable Next; recipient counterproposal shows donor response and generic SMS; paired panel layout visually checked. This scenario explorer does not mutate the main prototype or send messages. Saved as a separate local demo, not deployed to demo.freedme.org.
